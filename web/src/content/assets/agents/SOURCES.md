# Agent icons

Brand marks that identify each platform in the provider switcher. The trademarks
belong to their owners and are used here only to name the product in a local,
personal dashboard. All three are static SVG with no scripts or external references.

| File | Platform | Source | Changes |
| --- | --- | --- | --- |
| `codex.svg` | Codex (OpenAI) | Lobe Icons `@lobehub/icons-static-svg` 1.106.0, `icons/codex-color.svg` (MIT). OpenAI publishes no standalone Codex mark for download; this rendition was compared with the icon OpenAI ships in its own app. | White tile removed. The chevron and underscore were holes showing that tile, so they are now painted white; the viewBox is cropped to the cloud. The artwork itself is unchanged. |
| `claude-code.svg` | Claude Code (Anthropic) | Anthropic press kit, "Claude Spark - Clay": the mark of the official "Claude Code" lockup. | None. |
| `antigravity.svg` | Antigravity (Google) | Brand asset of antigravity.google, `antigravity-icon__full-color.svg`. | None. |

Downloaded 2026-11-25. The site favicon of antigravity.google was not used: it
recolors itself after the operating system's appearance, which can disagree with
this app's own theme switch.
